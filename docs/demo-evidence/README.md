# Demo evidence

Pages that the live demo (`scripts/demo.mjs`) links as evidence. They are labelled DEMO records written for the test;
GenLayer validators fetch them from GitHub during adjudication exactly as they would fetch any other public page.

| File | Used by | Shows |
|---|---|---|
| `order-1001.md` | the client's evidence in the upheld dispute | paid, promised in 24 h, not delivered after 48 h |
| `order-1002.md` | the client's evidence in the dismissed dispute | paid and delivered in 8 h 40 min, client confirmed |
| `delivery-1002.md` | the agent's counter-evidence in the dismissed dispute | the delivery receipt |
